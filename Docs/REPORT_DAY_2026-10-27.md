## 3. VR-УПРАВЛЕНИЕ ПО СТАНДАРТУ QUEST/PICO

Новый модуль `KvXrActions.cs` + чтение кнопок в `KvXrInputSource`:

| Кнопка | Действие (как в стандартных Quest-приложениях) |
|---|---|
| **A** (правый primary) | Подтвердить/выбрать — то же, что курок, с арбитражем «не над интерфейсом» |
| **B** (правый secondary) | Назад/отмена/закрыть окно (эквивалент Esc): меню → окно → сброс сценария |
| **X** (левый primary) | Стартовое меню (открыть/закрыть) |
| **Y** (левый secondary) | Панель у руки (показать/скрыть) |
| Левый стик | Движение/телепорт (было) |
| Правый стик | Поворот шагами 30° (было) |
| Курок | Выбор иконки/точки (было, арбитраж §42) |
| Грип | Захват окна (было) |

Принципы: фронт нажатия (одно нажатие — одно действие), приоритет B (аварийный выход),
A дублирует курок (никто не переучивается). Бинды VR/MR в окне F12 заменены с заглушек на реальные.

## 4. APK С ПОДПИСЮ (дефект сборки найден и исправлен)

Сборка падала: `Unable to sign the Android application … No keystore passwords were found`.
Причина: скрипт вызывал `KvXrTools.BuildAndroidApk` (без настройки подписи), а пароли Unity
в проект не сохраняет (и правильно). Исправлено: вызов `KvAndroidSigning.BuildSignedApk`
(настройка + сборка в одном сеансе). Плюс:
- **Создан junction `C:\KazistovVv_Build` → новая копия**: латинский путь для Gradle (без него
  Android-сборка падает на кириллице — Б6/А6) + совместимость 21 ссылки в Tools/*.ps1.
- Итог: **APK 183 МБ, ошибок 0, подпись постоянным ключом** (CN=KazistovVv,
  SHA-256 `3d8430c9b5b65e26…`) — отпечаток стабилен, регистрация в PICO Developer Center корректна.
- Политика отсечения шейдеров работает: `Simple Lit 221 184 → 768`.
