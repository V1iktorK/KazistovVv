## ОТКЛОНЁННЫЕ ВАРИАНТЫ

| Вариант | Почему отклонён |
|---|---|
| AR-сцена на базе ПК-сцены `MainScene` | Сцена авторская и **смешанная** (HDRP-камера/тома + URP-свет), интерфейс 1920×1080 с иконками 24 px и hover — для пальца не годится; Android = URP, HDRP-материалы ангара под URP дают дефект (разведка 02.11.2026) |
| AR «картинка камеры + объекты в воздухе» без якорей | Прямой запрет S3.1/S3.2; проверка Б3/Б4 («не плывёт», «обход стола») была бы невыполнима |
| Привязать AR-камеру к объекту/миру (двигать камеру вручную) | Камерой в AR владеет AR Foundation; ручное движение = «двойное управление», тряска и рассинхрон с реальным миром |
| Добавить ARCoreLoader в Standalone/Editor и тестировать в обычном Play Mode | ARCore не работает в редакторе; для редактора есть только XR Simulation, а он требует отдельного пакета-загрузчика и графики. Проверка в редакторе — тесты + сцена; на устройстве — владелец |
| Оставить стартовой сценой `XrMain` и определять AR внутри неё | Две сцены должны быть раздельными (S3.5 «не менять XrMain»), а выбор режима нужен ДО загрузки сцены |
| Кнопка/переключатель режима VR/AR до запуска | Прямое требование S1.7: «человек не должен ничего настраивать до запуска» |
| Масштабировать AR-мир под планшет | Масштаб 1:1 — требование В1; масштабирование сделало бы робота игрушкой |
| Изменять `KvXrGroupPanel`/`KvXrUiPointer` под касания | В VR они работают и покрыты тестами; у них уже есть публичные точки `TryAim`/`PressIndex`/`Aiming` — правка не нужна и рискованна |
| Пакет `com.unity.xr.arkit` (iPhone) | Вне объёма (S5 «что не входит»): AR только Android+ARCore |
| Отдельное AR-приложение / отдельный APK | Прямой запрет S1: «ОДНО приложение с новым режимом» |

## ИЗВЕСТНЫЕ ЛОВУШКИ, ПОДТВЕРЖДЁННЫЕ В ЭТОЙ СЕССИИ

| Ловушка | Как выглядела | Как лечится |
|---|---|---|
| `AddAnchor` в AR Foundation 6 | его нет — код не компилируется | `AttachAnchor`/`TryAddAnchorAsync` |
| Структура сравнивается с `null` (`surface == null`) | `error CS0019` при компиляции | проверять `surface.valid` |
| `using System;` + `using UnityEngine;` → `Object.` неоднозначен | `CS0104` | писать `UnityEngine.Object.…` |
| Кириллица в пути ломает Gradle | сборка APK | латинская копия `C:\KazistovVv_Build` + `GRADLE_USER_HOME=C:\GradleHome` |
| Два Unity на одном Library (junction) | «Exiting … return code 1» | блокировка `C:\KazistovVv_Build\.unity_lock` |
| Первый запуск на шлеме: диалог разрешений, XR ещё не активен | режим навсегда VR (дефект S45) | ждать `isInitializationComplete` (BootAr) и готовность XR (KvXrRig) |
| `KeyNotFoundException`/`NullReferenceException` при старте без ARCore | сообщение Ж1 | проверка состояния сессии и понятный экран, никаких исключений |
