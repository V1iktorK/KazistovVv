позиция в дереве · `command id` (если элемент идёт через реестр `KvCommands`) · обработчик
(файл:строка → фактический вызов в `Execute`) · что реально делает код · известный замер
(`effect=` из отчёта 11.11) · дефект/заглушка · потенциал. **Пустой замер = элемент прогоном не
проверялся** (это не «не работает», а «нет данных»); это всегда написано явно.

```

├─ KvToolbar      — панель инструментов под меню           (KvToolbar.cs + KvToolbarGroups.cs)

├─ KvTooltip      — всплывающие подсказки                  (Core/KvTooltip.cs)
└─ KvStatusBar    — строка состояния, 22 px снизу          (KvStatusBar.cs)

KazistovVvDockCanvas (ScreenSpaceOverlay, порядок 500)     ← КАНАВС DOCK-ПАНЕЛЕЙ
├─ Dock_Дерево моделей   (KvDockPanel + KvTreeView)
├─ Dock_Свойства         (KvDockPanel + KvPropertiesView)
├─ Dock_Настройки и справка (KvDockPanel + KvSettingsView)
```

Команды живут в реестре `KvCommands` (`Core/KvCommands.cs:66`): **161 команда**
(149 статических регистраций + 12 моделей роботов, `KvRobotCommands.RegisterModels`).
Кнопки тулбара, пункты меню и палитра строятся ИЗ этого реестра, поэтому новая кнопка
появляется регистрацией команды + её id в группе `KvToolbarGroups`.

## 1. СТРОКА МЕНЮ (`KvMenuBar.cs`)


**Каркас.** 6 кнопок меню (`KvMenuBar.cs:19`, массив `Menus`) + подпись-«имя проекта» справа
(`SetInfo`, `KvMenuBar.cs:113`) + `KvMenuBlocker` (`KvMenuBar.cs:118`, клик закрывает меню).
Выпадающий список строится `BuildDropdown()` (`KvMenuBar.cs:171`) **из реестра команд** по полю
`MenuPath`: `parts[0]` — меню, `parts[1]` — заголовок группы (рисуется как текст, не кнопка),
остальные части — вложенные пункты. Пункт рисуется `AddItem()` (`KvMenuBar.cs:260`):
галка состояния + подпись + горячая клавиша справа; клик → `CloseMenu()` → `KvCommands.Invoke(id)`
(`KvMenuBar.cs:329`). Недоступная команда (`Enabled == false`) — строка серая, `interactable=false`.
Пересборка списка — только при смене «отпечатка» (`MenuFingerprint`, `KvMenuBar.cs:402`).
Закрытие: клик по блокеру, `Esc` (`KvMenuBar.cs:528`), повторное нажатие того же меню.

## 2. ТУЛБАР (`KvToolbar.cs` + `KvToolbarGroups.cs`)


**Как строится.** `ToolbarLayout()` (`KazistovVvUIManager.cs:1156`) собирает плоский список id из
групп `KvToolbarGroups.All` → `toolbar.Build(...)` (`KvToolbar.cs:104`) → `RebuildGrid()`
(`KvToolbar.cs:185`): группы раскладываются вручную, при нехватке ширины группа уходит на следующую
полосу целиком; между группами — вертикальный разделитель (`AddSeparator`, `KvToolbar.cs:397`).
Каждая группа имеет **ручку** слева (`AddGroupHandle`, `KvToolbar.cs:379`) — узкую кнопку с
иконкой, по клику открывающую выпадающий список команд группы (`ShowGroupMenu`, `KvToolbar.cs:434`).
Кнопка команды создаётся `AddButton()` (`KvToolbar.cs:344`): `KvWidgets.IconButton(... "Cmd_"+id ...)`
→ при клике `KvCommands.Invoke(id)`; подсказка = название + описание + группа + горячая клавиша.
`Refresh()` (`KvToolbar.cs:573`) десять раз в секунду обновляет ТОЛЬКО состояния (галки, доступность,
иконки) — тексты подсказок считаются один раз при сборке.

**Режимы раскладки** (`KvSettings.ToolbarLayout`): 0 «Авто» (колонки от ширины канваса),
1 «Широко», 2 «5 в ряд» (одна плоская группа «Все команды»). **Компактный режим**
(`KvSettings.ToolbarCompact`, `KvToolbar.cs:62`): скрывает 10 «редких» команд —
`help.open, edit.undo, edit.redo, view.theme, ui.settings, startmenu.show, tut.toggle, demo.quick,
report.make, cameras.tab` (они продублированы пунктами меню). Состояние свёрнутости групп —
в `PlayerPrefs` (`KvSettings.IsToolbarGroupCollapsed`).

**Состав: 8 групп, 122 кнопки команд + 8 ручек групп + сегмент «Верстак» (2 положения).**
