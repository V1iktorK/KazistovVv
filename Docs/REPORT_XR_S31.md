## 3. Два ограничения метода (важно знать, это НЕ дефекты проекта)

1. **Датчик присутствия.** Без надетого шлема экран гаснет и приложение получает паузу через 1,5 с:
   `ProximityPowerPolicyController: psensor gotoSleepFromPsensor` → `Handle cmd APP_CMD_STOP(15)`.
   Обойти программно **нельзя**: сборка production, `adb root` недоступен
   (`adbd cannot run as root in production builds`), `setprop pvr.factorytest.never.sleep 1` и
   `persist.psensor.sleepmode 0` отклоняются, `svc power stayon true` не помогает — автосон идёт
   по датчику, а не по таймауту экрана. **Лечение: надеть шлем или накрыть датчик.**
2. **Снимок экрана не показывает VR-кадр.** `adb exec-out screencap` для работающего VR-приложения
   отдаёт **полностью чёрный кадр** (41 КБ, 100 % чёрных пикселей), хотя приложение живо и рисует
   90 кадров/с: VR-изображение уходит прямо в композитор устройства, 2D-поверхности для захвата нет.
   **Следствие: техническая часть приёмки — журналом; визуальная — только глазами владельца.**
