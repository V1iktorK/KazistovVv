## Б. ОТКРЫТЫЕ ПРОБЛЕМЫ

### Б2. Взрыв числа вариантов шейдеров — ПРИЧИНА НАЙДЕНА И ОТСЕЧЕНА: `URP/Lit` 442 368 вариантов

**Карточка переписана 08.10.2026 (второй проход) по настоящей причине.** Прежняя формулировка
(«единственный оставшийся барьер сборки») **не верна**: сборка закрыта — **APK собран**
(`KazistovVv.apk`, 90,8 МБ, SHA256 `E9B181BEC22030467FCD06F04664D5AEFC6D1703C77F259E72343B473EE3F53A`,
копия `Builds\KazistovVv.apk`, идентификатор `com.KazistovVv.app`), сборка заняла **70,3 мин**.

| | |
|---|---|
| **Настоящая причина (главное)** | шейдер **`Universal Render Pipeline/Lit`, проход `ForwardLit`**: полный набор **36 238 786 560** → фильтрация **113 246 208** → встроенное отсечение **442 368** — и **URP это НЕ срезал**. Это и была основная цена долгих сборок, а не постобработка |
| **Почему URP не срезал** | в `Assets/Settings/Mobile_RPAsset.asset` значения **предфильтрации остались по умолчанию**: `m_PrefilterModeMainLightShadows: 4` (SelectAll), `m_PrefilteringModeAdditionalLight: 5` (SelectAll), остальные — Select. То есть «оставлять всё» — при том что там же: `m_SoftShadowsSupported: 0`, `m_AdditionalLightShadowsSupported: 0`, `m_AdditionalLightsRenderingMode: 1` (повершинный), `m_ShadowCascadeCount: 1`, SSAO в мобильном рендерере нет, тумана (`m_Fog: 0`) и карт освещения (`m_Lightmaps: []`) в сценах нет |
| **Решение** | своя политика отсечения ключевых слов `Assets/_Project/01_Scripts/Editor/KvUrpKeywordPolicy.cs`: снимает слова, которых проект **не исполняет** (`_ADDITIONAL_LIGHTS`, `_ADDITIONAL_LIGHT_SHADOWS`, `_SHADOWS_SOFT*`, `_MAIN_LIGHT_SHADOWS_CASCADE`, `_SCREEN_SPACE_OCCLUSION`, `FOG_LINEAR/EXP/EXP2`, `LIGHTMAP_ON`, `DIRLIGHTMAP_COMBINED`, `DYNAMICLIGHTMAP_ON`, `LIGHTMAP_SHADOW_MIXING`, `SHADOWS_SHADOWMASK`, `_FORWARD_PLUS`, `_CLUSTER_LIGHT_LOOP`, `_DBUFFER_MRT1..3`). **У каждого слова в журнале ПРИЧИНА**, и **если настройка не прочиталась — слово НЕ снимается** («не знаю» никогда не превращается в «отсекаем») |
| **Результат (по журналу сборки)** | `URP/Lit ForwardLit` **442 368 → 1 536** (обработка **18,9 с**), `ClusterDeferred` 1 536 → 64, `FinalPost` 2 560 → 192, `UberPost` 46 080 → 48, террейн-шейдеров в сборке **нет** |

**Закрыто:** гашение сцены перенесено в `Awake` (`KvXrSceneEmpty`) — выполняется до любого `Start`,
поэтому меню сразу видит 0.

### Б59. РОБОТ ПОПАДАЛ В РАЗДЕЛ «СТОЛ» (найдено 25.10.2026 в шлеме, ЗАКРЫТО)

**Симптом.** `ПАНЕЛЬ: НАЖАТИЕ «Стол: 6-осевой робот_101404»` — владелец нажимал робота как стол.

**Причина.** Список столов собирался по компоненту `RegisteredObject`, а клон робота этот компонент
получает для учёта в дереве.

**Закрыто:** `KvXrGroupPanel.RefreshStartLists` пропускает объекты с `RobotController`.

### Б60. ВТОРОЙ (ЛЕВЫЙ) ЛУЧ ТОЖЕ НЕ УПИРАЛСЯ В МИР (найдено 25.10.2026 самостоятельной проверкой, ЗАКРЫТО)

**Как нашлось.** После починки правого луча (Б56) я проверил поиском, где ещё нет `Physics.Raycast`, и
нашёл `KvXrSecondaryRay`: он проверял только панели (`TryAim`, `TryHitPanelSurface`), а геометрию сцены
не видел. То есть левый лазер пролетал сквозь стол и робота.

**Закрыто:** добавлен `Physics.Raycast` по маске слоёв (без `IgnoreRaycast`), поле `AimingAtWorld`.

### Б61. СТРОКА ЖУРНАЛА ПЕЧАТАЛАСЬ ТРИЖДЫ НА ТРЁХ ЯЗЫКАХ (найдено 25.10.2026, ЗАКРЫТО)

**Симптом в журнале шлема:**
`[Singularity] СИНГУЛЯРНОСТЬ · Wrist · запястье · |q5| = 0,0°`,
затем `[Singularity] SINGULARITY · wrist · wrist · |q5| = 0,0°`,
затем `[Singularity] SINGULARITÄT · Handgelenk · Handgelenk · |q5| = 0,0°`.

**Причина.** `KvLoc` на Android читает словари **асинхронно, по одному файлу** (`ru.json`, `en.json`,
`de.json`…). Пока шла загрузка, `Status` менялся на каждом шаге, и `Report()` печатал его как «новый».

**Закрыто:** добавлен признак готовности `KvLoc.FilesLoaded`; `KvSingularityVisualizer.Report()`
не печатает, пока каталог не загружен.

### Б62. ЧЕСТНАЯ СТРОКА ПРО ГОЛОС БЫЛА МЁРТВЫМ КОДОМ (найдено 25.10.2026, ЗАКРЫТО)

**Симптом.** Экран «Ввод» писал свой текст «голос недоступен (нет движка распознавания)», а класс
`KvXrVoiceStatus` (с причиной «нет appID PICO») не вызывался **нигде, кроме тестов**. Владелец не узнавал,
ЧТО нужно сделать, чтобы голос заработал.

**Закрыто:** экран «Ввод» берёт строку из `KvXrVoiceStatus.Line(HasVoiceAppId(), HasMicrophonePermission())`
и печатает её в журнал. Три состояния: нет appID / нет разрешения `RECORD_AUDIO` / доступен.

### Б63. ДИАГНОСТИКА ЗОН СЧИТАЛА 2 ВИЗУАЛИЗАТОРА ИЗ 6 (найдено 25.10.2026, ЗАКРЫТО)

**Симптом.** Строка `ЗОНЫ: видимо 2` не менялась, хотя команды `view.heatmap`, `view.clearance`,
`zone.*` выполнялись: теплокарта, зазоры и запретные зоны в счёт не шли.

**Закрыто:** `VisibleVisualizers` считает все шесть — зона достижимости, сингулярности, теплокарта
достижимости, теплокарта зазоров, запретные зоны (силы считаются через вкладку верстака).

**Заодно:** добавлена строка о попадании луча в мир
`[KvXr] ЛУЧ: попадание в «…» на 1.20 м (геометрия сцены)` — иначе пункт «луч упирается» нечем доказать
без глаз владельца.
