## Б. ОТКРЫТЫЕ ПРОБЛЕМЫ

### Б2. Взрыв числа вариантов шейдеров — ПРИЧИНА НАЙДЕНА И ОТСЕЧЕНА: `URP/Lit` 442 368 вариантов

**Карточка переписана 08.10.2026 (второй проход) по настоящей причине.** Прежняя формулировка
(«единственный оставшийся барьер сборки») **не верна**: сборка закрыта — **APK собран**
(`KazistovVv.apk`, 90,8 МБ, SHA256 `E9B181BEC22030467FCD06F04664D5AEFC6D1703C77F259E72343B473EE3F53A`,
копия `Builds\KazistovVv.apk`, идентификатор `com.KazistovVv.app`), сборка заняла **70,3 мин**.

| | |
|---|---|
| **Настоящая причина (главное)** | шейдер **`Universal Render Pipeline/Lit`, проход `ForwardLit`**: полный набор **36 238 786 560** → фильтрация **113 246 208** → встроенное отсечение **442 368** — и **URP это НЕ срезал**. Это и была основная цена долгих сборок, а не постобработка |
| **Почему URP не срезал** | в `Assets/Settings/Mobile_RPAsset.asset` значения **предфильтрации остались по умолчанию**: `m_PrefilterModeMainLightShadows: 4` (SelectAll), `m_PrefilteringModeAdditionalLight: 5` (SelectAll), остальные — Select. То есть «оставлять всё» — при том что там же: `m_SoftShadowsSupported: 0`, `m_AdditionalLightShadowsSupported: 0`, `m_AdditionalLightsRenderingMode: 1` (повершинный), `m_ShadowCascadeCount: 1`, SSAO в мобильном рендерере нет, тумана (`m_Fog: 0`) и карт освещения (`m_Lightmaps: []`) в сценах нет |
| **Решение** | своя политика отсечения ключевых слов `Assets/_Project/01_Scripts/Editor/KvUrpKeywordPolicy.cs`: снимает слова, которых проект **не исполняет** (`_ADDITIONAL_LIGHTS`, `_ADDITIONAL_LIGHT_SHADOWS`, `_SHADOWS_SOFT*`, `_MAIN_LIGHT_SHADOWS_CASCADE`, `_SCREEN_SPACE_OCCLUSION`, `FOG_LINEAR/EXP/EXP2`, `LIGHTMAP_ON`, `DIRLIGHTMAP_COMBINED`, `DYNAMICLIGHTMAP_ON`, `LIGHTMAP_SHADOW_MIXING`, `SHADOWS_SHADOWMASK`, `_FORWARD_PLUS`, `_CLUSTER_LIGHT_LOOP`, `_DBUFFER_MRT1..3`). **У каждого слова в журнале ПРИЧИНА**, и **если настройка не прочиталась — слово НЕ снимается** («не знаю» никогда не превращается в «отсекаем») |
| **Результат (по журналу сборки)** | `URP/Lit ForwardLit` **442 368 → 1 536** (обработка **18,9 с**), `ClusterDeferred` 1 536 → 64, `FinalPost` 2 560 → 192, `UberPost` 46 080 → 48, террейн-шейдеров в сборке **нет** |
| **Чем закреплено** | `KvShaderVariantTests.cs` (**5** тестов) и `KvUrpKeywordPolicyTests.cs` (**4** теста: `Policy_KeepsKeywordsTheProjectUses`, `Policy_NamesReasonForEveryStrippedKeyword`, `Policy_StripsFogAndLightmapKeywords_WhenScenesDoNotUseThem`, `Policy_StripsShadowAndLightKeywords_ThatAssetDisables`) |
| **ДВЕ ОПРОВЕРГНУТЫЕ ГИПОТЕЗЫ (не проверять снова)** | (а) **`-nographics` — не причина**: без него те же 442 368 вариантов, хотя настройки URP через `TryGetRenderPipelineSettings` без него действительно находятся; (б) вывод §28 «виновата подмена глобального умолчания графики» **не подтвердился** |
| **Что сделано раньше (остаётся в силе)** | (а) выключены шейдеры террейна: `Assets/Settings/UniversalRenderPipelineGlobalSettings.asset`, `m_IncludeTerrainShaders: 1 → 0` (правка **через ассет**: штатный `GraphicsSettings.TryGetRenderPipelineSettings<URPTerrainShaderSetting>` вернул **false**); (б) из `Assets/Settings/DefaultVolumeProfile.asset` убран мусор: было **28 блоков** при **19** компонентах в списке профиля, среди них компоненты тестовых сборок Unity (`CopyPasteTestComponent1/2/3`, `TestVolume`, …) и **5 объектов с потерянным скриптом** (`m_Script: {fileID: 0}`) — ссылок на них в проекте не было **ни одной**; (в) свой отсекатель постобработки `Assets/_Project/01_Scripts/Editor/KvShaderVariantStripper.cs` (`IPreprocessShaders`) для `UberPost`/`FinalPost` — работает **только** если в сценах сборки **ни одна камера не рисует постобработку** (`m_RenderPostProcessing: 1` читается из файлов сцен; умолчание URP — `false`). **Если постобработку включат, отсечение само перестанет работать** |
| **Инструменты** | меню `Tools/KazistovVv Рендер/7. Отсечь лишние варианты шейдеров (Б2)`; батчмод — `KazistovVvXrEditor.KvRenderPipelineTools.StripUnusedVariantSources` |

### Б15. Словари локализации НЕ ЧИТАЮТСЯ на устройстве — ИСПРАВЛЕНО 13.10.2026 (ждёт проверки на шлеме)

| | |
|---|---|
| **Симптом** | в журнале шлема при запуске: `[KazistovVv] Язык интерфейса: Русский (Russian) · языков: 7 · **файлов прочитано: 0** · строк всего: 14 · каталог: jar:file:///data/app/~~9gu2hL1…/com.KazistovVv.app-…` |
| **Что это значит** | семь словарей `Assets/StreamingAssets/kazistovvv_i18n/{ru,en,zh,es,de,fr,ja}.json` на устройстве **не открылись**: «файлов прочитано 0», в словарях оказалось только **14** строк. Остальные строки интерфейса приходят из рантайм-таблиц `KvLocExtra*` (в том же журнале их 4186) и из русских литералов кода |
| **Чем мешает** | на шлеме интерфейс фактически **одноязычный**: строки, которые лежат в JSON (их большинство), не подставляются. В редакторе путь к `StreamingAssets` обычный — поэтому дефект там не виден |
| **Вероятная причина** | на Android `StreamingAssets` лежат ВНУТРИ APK (`jar:file://…!/assets/…`); обычное чтение файла такой путь не понимает — нужен `UnityWebRequest` (он умеет `jar:`) или перенос словарей в `Resources`. Требует проверки кодом `KvLocalization` |
| **Что нужно** | починить чтение словарей на Android и закрепить проверкой на устройстве: после запуска в журнале должно быть **`файлов прочитано: 7`** |
| **Что сделано (раунд 4)** | добавлены `NeedsAsyncFileLoad()`, `FileUrl()` и корутина `LoadFilesAsync()`: семь словарей читаются через **`UnityWebRequest`** (он понимает `jar:`), после чего подписи пересобираются событием `Changed`. **Десктопный путь не изменён** — на компьютере папка видна и работает прежнее чтение. Разбор JSON вынесен в общий `ApplyLanguageJson`, поэтому «прочитано из пакета» ведёт себя как «прочитано с диска». Закреплено 5 тестами (`KvLocalizationFileTests.cs`), в том числе «в редакторе асинхронный путь НЕ включается» |
| **Как проверить на устройстве** | после запуска приложения в журнале должно быть `[KvLoc] словари с устройства: прочитано 7` и `файлов прочитано: 7`, а подписи интерфейса — на выбранном языке |
| **Подробно** | `Logs\wave3-startup.log` (строка `[KazistovVv] Язык интерфейса…`); `Docs\REPORT_XR_S32.md` §8.3 |
