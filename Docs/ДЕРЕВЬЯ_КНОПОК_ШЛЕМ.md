**Правила чтения.** Каждая кнопка шлема создаётся одним местом — `KvXrGroupPanel.CreateIcon`
(`KvXrGroupPanel.cs:3008`), там же она попадает в список целей луча; нажатие идёт
`PressIndex` (`KvXrGroupPanel.cs:2877`) → лямбда обработчика. Надписи (`CreateLabel`,
`KvXrGroupPanel.cs:2463`) кнопками НЕ являются и в деревья не входят.
Подпись появляется по удержанию луча 0,5 с (`LabelDwellSeconds`, `KvXrGroupPanelLayout.cs:166`).

**Обозначения замера.** «замер устарел» — элемент из отчёта 11.11.2026 получил
`ok=0 исчез` из-за старого дефекта пересборки панели (фикс UI_SWEEP 13.11.2026); по
структуре элемент верен, по результату нужен НОВЫЙ прогон. «нет в прогоне» — кнопка
существует в коде, но прогон её не нажимал.

## 3. ДЕРЕВО C — ВЕЕР КОМАНД (все страницы)

Открытие: `OpenGroup` (:2512) → `level = GroupFan`, `fanPage = 0` (каждая группа открывается
с первой страницы). Построение `BuildFanLevel` (:811):

* отбираются ТОЛЬКО команды, существующие в реестре (`KvCommands.Get(id) != null`, :831);
* страниц по 12 (`FanPageSize`, :236), `pageCount = ceil(n/12)` (:850);
* на странице до 12 команд + 2 стрелки + центр = 14 иконок (`MaxFanIcons`);
* стрелки: `Fan_Prev` (только если `fanPage > 0`, :899) и `Fan_Next` (только если не последняя, :905);
  подписи «Страница N из M»;
* центр `Fan_Close` (:912) — выход из веера;
* команда НЕ закрывает веер после нажатия (:2574) — выход только центральной иконкой;
* `FanTurnPage` (:935) — листание, `Rebuild()`.

## 9. ДЕФЕКТЫ, ЗАГЛУШКИ И ПОТЕНЦИАЛ (сводно по шлему)

**Дефекты (найдены разбором кода/замера):**

1. **«Переместить робота» недостижима.** `KvXrStartMenuRows.Robots()` добавляет строку
   `MoveRobotRowLabel` (`KvXrStartMenuRows.cs:48/56`), действие `MoveRobotToFixedSpot`
   (`KvXrStartRowAction.cs:60`) и обработчик в `PressStartRow` (`KvXrGroupPanel.cs:2208`) —
   но `StartContentLabels` (:2027–2033) строит только 3 строки создания, поэтому строки нет на панели,
   а `ActionFor` для `row = existing+3` недостижим. Требование владельца 12.11.2026 в интерфейсе отсутствует.
2. **Две кнопки с подписью «Настройки» на одном уровне**: группа `Group_ui «Настройки»` и экран
   `Screen_SettingsScreen «Настройки»`. Подписи появляются по удержанию 0,5 с — оператор не отличит,
   а в путях замера `ПанельШлема/иконки групп/Настройки` неоднозначен (в отчёте под этим именем
   ровно 1 элемент при 13 кнопках уровня).
3. **Замер 11.11 устарел**: 115 из 161 элемента — «исчез» из-за пересборки панели; VR-прогон пуст.
   «Сейчас» для этих кнопок код подтверждает, замер — нет.
4. **Дыры прогона по разделу «Робот»**: объявлено 6 пунктов, press/element только у 4 —
   «Добавить 6-осевой робот» и «Добавить SCARA» не получили результата.
5. **`Set_Toggle` не проверен**: переключатель параметров 4–6 («Второй луч», «Рука луча», «Режим VR/MR»)
   строится только при `settingsIndex ≥ 4`, прогон оставался на параметре 1.
6. **11 элементов с `interactable=false`** в замере (8 групп, 2 крестика окон, `Cmd_shot.screenshot`),
   тогда как `CreateIcon` (:3008–3083) никогда не выставляет `Button.interactable` — код панели
   физически не может отключить эти кнопки. Расхождение «замер ↔ код»: нужно либо правило прогона
   пересмотреть, либо найти, кто гасит кнопку.
7. **Пояс окон без кнопки возврата**: `KvFeatureWindow` кладёт окно на пояс

   на пояс, недостижимо. В шлеме пояс не отрисовывается вообще.
