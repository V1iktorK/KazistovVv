# ПЛАН §40-ИСПРАВЛЕНИЕ: ЛУЧ ЛОВИТ КАЖДУЮ КНОПКУ ПАНЕЛИ (24.10.2026)

Волна открыта по прямому указанию владельца сразу после приёмки §40:
«Меня ДО ПЕРЕНОСА не устраивает что не приклеивается лазер к новым кнопкам внизу контроллера, что
выстроены в ряд. информация, яркость и тд».

Порядок работ — по правилам проекта ([S7]): **неясное — спросить → план → согласование → тесты →
реализация → прогон новых и всех прежних тестов → записи в планах → отчёт**. Неясного в этой волне
нет: дефект назван, поведение описано словами владельца, границы (что НЕ трогать) известны.

## 3. ПРИЧИНА, УСТАНОВЛЕННАЯ ПО КОДУ

Кнопка = картинка на канвасе + смещение в списке целей луча (`currentOffsets`). Смещения вписывались
вручную в каждом построителе уровня; при добавлении ряда экранов и кнопок внутри экранов список не
расширили. Подробный разбор — `Docs/REPORT_XR_S40_FIX.md` §2.
