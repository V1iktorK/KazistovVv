## 0. Что должно быть надето и подключено

1. Шлем **на голове** (или датчик присутствия закрыт): без этого приложение через ~1,5 с получает
   `APP_CMD_STOP` и засыпает — проверять будет нечего.
2. Контроллеры **в руках и включены** (для пунктов 1–3), затем **положить их на стол** (пункт 4–5:
   кисти и жесты).
3. Кабель USB-C подключён, отладка по USB включена, `adb devices` показывает `A9210`.
4. Заряд проверен: `adb shell dumpsys battery` → `level`.

## 1. Установка и сверка, что в шлеме ИМЕННО эта сборка

```
powershell -NoProfile -ExecutionPolicy Bypass -File Tools\device-install-and-log.ps1 -Mode Install
```

| # | Доказательство | Как проверить |
|---|---|---|
| 1.1 | установка прошла | вывод скрипта: `Success` |
| 1.2 | **в шлеме наша сборка, а не прежняя** | `adb shell pm path com.KazistovVv.app` → `adb shell ls -l <путь>` (размер — пятое поле) против `(Get-Item Builds\KazistovVv.apk).Length`; числа обязаны **совпасть** |
| 1.3 | падений нет | в журнале нет `FATAL EXCEPTION` / `AndroidRuntime` |

> Пункт 1.2 — не формальность: 15.10.2026 владелец смотрел в шлем, где стояла сборка **до правок**.

**Запуск — ТОЛЬКО из библиотеки шлема.** С включённым PICO SDK (`pvr.app.type = vr`) запуск по
`adb` (`am start`, `monkey`) система снимает: `Activity not started … app died`. Поэтому журнал
снимается потоком **до** нажатия иконки в библиотеке:

```
powershell -NoProfile -ExecutionPolicy Bypass -File Tools\_stage_a\device-stream-log.ps1 -Tag s37 -Seconds 300 -NoRestart
```

Флаг `-NoRestart` обязателен: без него скрипт сам запускает приложение через `monkey`, а это
запрещённый способ проверки.

### 3.2. Дальше — кисти и жесты (контроллеры можно не класть, но жест должен быть отчётливым)

> **ВАЖНО (сборка §38, строгий режим).** Жест считается ТОЛЬКО когда:
> 1) рука **в поле зрения** — впереди не меньше 0,15 м и не дальше 0,9 м от глаз (опущенная рука не считается);
> 2) **есть что сделать** — щипок без наведённой иконки не считается, «выход из веера» при закрытом веере не считается;
> 3) поза **отчётливая**: «раскрытая ладонь» — только **пальцами ВВЕРХ**, как жест «стоп» (опущенная или расслабленная кисть — не жест).
>
> Цена строгости: иногда жест придётся повторить. Это ваш выбор: «лучше не сработает, чем сработает лишний раз».

| # | Пункт | Как делать | Ответ |
|---|---|---|---|
| 3.2.1 | Кисти видны | Поднимите руки перед собой — точки суставов (12 мм), кончик указательного крупнее (18 мм) | ☐ ☐ |
| 3.2.2 | **Диагностика кистей** | В журнале строка `ОТСЛЕЖИВАНИЕ РУК: … · запястье (…) · камера (…) · до камеры 0.xx м` — число должно быть 0,2–0,9 м | ☐ ☐ |
| 3.2.3 | **Щипок = нажатие** | Наведите луч на иконку, затем щипок большим и указательным (держать ≥ 0,2 с) | ☐ ☐ |
| 3.2.4 | **Раскрытая ладонь = панель вкл/выкл** | Ладонь **пальцами вверх**, как «стоп», держать ≥ 0,8 с | ☐ ☐ |
| 3.2.5 | **Указательный палец = следующая группа** | Указательный прямой, три остальных согнуты, держать ≥ 0,6 с | ☐ ☐ |
| 3.2.6 | **Щипок левой = выход из веера** | Сначала раскрыть веер, затем щипок левой рукой | ☐ ☐ |
| 3.2.7 | Ложных срабатываний НЕТ | Опустите руки, сожмите кулаки, расслабьте кисти — **ни одного** `ЖЕСТ:` в журнале | ☐ ☐ |

(включая крен). Если нужно ещё ближе/дальше — эти два числа меняются файлом, без пересборки.

**`sides.swap` — переключатель сторон рук (§37, найдено 21.10.2026).** Если модели контроллеров
снова окажутся не в тех руках: `sides.swap=1` — поменять местами, `0` — как назвал рантайм, ключа
нет — решает автоматика по положению рук относительно головы. Применяется на ходу и пишет строку
`[KvXr] СТОРОНЫ РУК: включён РУЧНОЙ переключатель sides.swap=1 · стороны ПОМЕНЯНЫ местами`.

## 6. ЕСЛИ ЧТО-ТО НЕ ТАК — СРАЗУ СНЯТЬ ДОКАЗАТЕЛЬСТВА

| Симптом | Сначала смотреть | Что это значит |
|---|---|---|
| контроллеров не видно, а в журнале `ИКОНКИ КОНТРОЛЛЕРОВ: показано 0` | строки `КОНТРОЛЛЕРЫ ПОЯВИЛИСЬ` и `поза` | нет позы (`НЕТ ПОЗЫ`) — контроллер не трекается; есть поза, а моделей нет — искать строку отката меша |
| модель контроллера висит на полу/в воздухе | `ИКОНКИ КОНТРОЛЛЕРОВ … правая (…)` | поза нулевая — модель обязана была скрыться; смотреть `HideGraceSeconds` |
| модели контроллера **розовые** | строку `материал наш (URP)` | материал не подменился — сообщить, вернуть примитивы файлом `visuals.mode=primitives` |
| панель большая/маленькая не так | `панель групп: … радиус …` | сравнить число в журнале с выбранным; правится `panel.radius` |
| иконки слипаются | `иконка … мм · просвет … мм` | проверить, что число радиуса не вышло за 0,08…0,42 |
| луч из левой руки, а не из правой | `Указатель: луч из …` и `ray.hand` | в файле подстройки выставить `ray.hand=right` |
| кистей нет | `ОТСЛЕЖИВАНИЕ РУК: …` | «подсистемы нет» → фича кистей; «поз нет» → положить контроллеры / включить отслеживание рук в настройках шлема |
| жесты не срабатывают | `ОТСЛЕЖИВАНИЕ РУК` и `ЖЕСТ:` | без кистей жестов нет; если кисти есть, а `ЖЕСТ:` нет — удержание/порог, смотреть строку `ПОДСТРОЙКА … жесты` |
| жест срабатывает сам | строки `ЖЕСТ: «…»` | сообщить; выключить файлом `gesture.enabled=0` |
| кадры просели | `PxrMetric` | выключить модели файлом `visuals.mode=off`, сравнить числа |
| камера не за головой | `Камера следует за головой` | компонент `KvXrHeadTracking` мёртв — это самое дорогое |

**Правило проекта (не изменилось):** «должно работать» — не результат. Пункт без строки в журнале
или без взгляда владельца считается **не проверенным**, и так и пишется в отчёте.
