# ШРИФТ ДЛЯ КИТАЙСКОГО И ЯПОНСКОГО — КУДА КЛАСТЬ

_Создано 30.10.2026 (S44), долг 5.27._

## Что здесь должно быть

Один файл шрифта с ПОЛНЫМ покрытием CJK (китайский + японский), имя — из списка
`KvLocalization.BundledCjkFontNames`. Достаточно положить файл в эту папку, переименовать его
в одно из имён списка, и код подхватит его сам: перезапуск, пересборка сцены и правки не нужны.

Положить, например:

```
Assets/Resources/KvCjkFont/NotoSansCJKsc-Regular.otf
```

## Почему это до сих пор не сделано

Файл весит 16–20 МБ и попадает В КАЖДУЮ сборку. Это решение владельца: оно влияет на размер APK
и требует выбора лицензии. Код готов; не хватает только файла.

## Какой шрифт брать

**МОЖНО (свободные лицензии):**

| Шрифт | Лицензия | Замечание |
|---|---|---|
| Noto Sans CJK SC | SIL Open Font License 1.1 | покрывает и китайский, и японский |
| Source Han Sans | SIL Open Font License 1.1 | тот же шрифт под другим именем |

**НЕЛЬЗЯ (лицензия Microsoft):** msyh (Microsoft YaHei), simsun, simhei, Meiryo, Yu Gothic,
MS Gothic. Их лицензия НЕ разрешает распространение в составе приложения — только использование
на своей машине. Тест `KvBundledFontTests` следит, чтобы они не попали в список.

## Что будет, пока файла нет

Ничего не ломается: поиск вернёт `null`, и приложение возьмёт системный шрифт (на Windows —
найдёт, на шлеме — нет). В журнале появится строка:

```
[KvLoc] системный шрифт с CJK-глифами не найден … китайский/японский текст будет квадратами
```

## Как проверить, что заработало

После добавления файла в журнале при выборе китайского или японского должно появиться:

```
[KvLoc] шрифт CJK взят из проекта: NotoSansCJKsc-Regular (из проекта) (язык zh)
```

Слово «из проекта» — признак того, что шрифт едет внутри сборки, а не взят с машины.
